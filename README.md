# Python Digital Clock Program
A desktop digital clock program built with Python and PyQt5.

This project was developed as part of my Python learning journey to practice GUI development, it displays the time in a graphical window and updates it automatically every 100 ms.

# Features
- Automatic time updates using QTimer of PyQt5.
- Simple and minimial GUI.
- Custom styling
- Real-time clock displaying H/M/S.

# Technologies Used
- Python
- PyQt5 (GUI framework)
